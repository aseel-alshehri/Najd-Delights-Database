# Najd Delights Database

An academic MySQL project for a restaurant database. It demonstrates relational table design and common SQL operations.

## Database tables
- `Customer` — customer details.
- `Dish` — menu items, categories, and prices.
- `Orders` — order dates, payment methods, and optional customer references.

## SQL concepts demonstrated
- Creating databases and tables
- Primary keys and foreign keys
- `NOT NULL`, `UNIQUE`, `DEFAULT`, and `CHECK` constraints
- Inserting and updating records
- Aggregate functions such as `MIN`, `MAX`, `COUNT`, `SUM`, and `AVG`
- `GROUP BY`
- `LEFT JOIN` and `INNER JOIN`
- Subqueries
- Creating and querying a view

## Requirements
- MySQL 8.x or another compatible MySQL environment.

## How to run
1. Open `najd_delights.sql` in MySQL Workbench.
2. Review the script before running it.
3. Execute the script.
4. Run the sample queries to inspect the results.

## Notes
- The script uses fictional sample names and placeholder phone numbers.
- The script does not drop an existing database.
- This project is an academic SQL exercise, not a production restaurant system.
